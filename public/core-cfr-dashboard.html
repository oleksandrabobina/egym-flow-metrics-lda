Deployment Frequency & Change Failure Rate Dashboard

ℹ️ About this report

This is the DORA Deployment Frequency & Change Failure Rate report for the Core — the Users & Locations, Core Workouts, API Platform, Operator Experience, Process Automation, Data Science, Digital Ops SW, Digital-Operations, MMS-Connect engineering teams. In plain words, it answers the question: how often does a release cause a problem. It is generated automatically every week from the same data feeds as the official DORA workbook, so the numbers match.
